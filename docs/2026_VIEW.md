# 2026 View - Upcoming Competition Data

## Overview

The "2026" view in the band_positions app displays upcoming competition data for NM Janitsjar (Wind Bands) and NM Brass (Brass Bands) 2026. This view shows progressive information as it becomes available leading up to the competitions.

## Data Stages

The system supports 4 progressive data stages:

1. **Stage 1: Division Lists** - Orchestra assignments to divisions announced
2. **Stage 2: Playing Schedule** - Play order, dates, times, and venues announced
3. **Stage 3: Pieces Announced** - Musical pieces selected by each orchestra
4. **Stage 4: Conductors Announced** - Conductor assignments finalized

## Data Sources

Data files are located in:
- Wind: `public/data/upcoming_wind_2026.json`
- Brass: `public/data/upcoming_brass_2026.json`

These files are generated from the band_data repository:
- Source: `../band_data/data/wind/upcoming/2026.json`
- Source: `../band_data/data/brass/upcoming/2026.json`

## Updating Data

To update the frontend with new upcoming competition data:

1. Update data in band_data repository:
   ```bash
   cd ~/apps/band_data
   # Edit data/wind/upcoming/2026.json or data/brass/upcoming/2026.json
   ```

2. Export to frontend:
   ```bash
   python scripts/export_upcoming_frontend.py
   ```

3. Rebuild frontend (if needed):
   ```bash
   cd ~/apps/band_positions
   npm run build
   ```

## Component Structure

### Main Component

**`src/lib/Upcoming2026.svelte`** - Displays upcoming competition data organized by division

Features:
- Loads both wind and brass data on mount
- Shows appropriate data based on current band type
- Displays stage badge indicating data completeness
- Shows division cards with orchestra lists
- For Stage 2+: Shows play times and venues
- For Stage 3+: Shows selected pieces
- For Stage 4: Shows assigned conductors

### Integration

The view is integrated into `App.svelte` as one of the primary navigation tabs:

```typescript
type ViewType = 'bands' | 'conductors' | 'pieces' | 'composers' | 'data' | 'repertoire' | '2026' | 'om' | 'innstillinger';
```

Navigation order: `['data', 'bands', 'conductors', 'pieces', 'composers', 'repertoire', '2026', 'om', 'innstillinger']`

## Data Schema

```typescript
interface UpcomingData {
  year: number;                    // 2026
  competition_type: 'wind' | 'brass';
  stage: 1 | 2 | 3 | 4;           // Data completeness stage
  divisions: UpcomingDivision[];
  location: string | null;         // "Trondheim"
  date_range: string | null;       // "20-21 mars 2026"
  last_updated: string;            // ISO timestamp
  notes: string;                   // Stage-specific notes
}

interface UpcomingDivision {
  name: string;                    // "Elite", "1. divisjon", etc.
  entries: UpcomingEntry[];
  play_date: string | null;        // "2026-03-21"
  venue: string | null;            // "Olavshallen, store sal"
}

interface UpcomingEntry {
  orchestra: string;               // Orchestra name
  division: string;
  play_order: number | null;       // Playing order (1, 2, 3...)
  play_datetime: string | null;    // "2026-03-21T09:30:00"
  venue: string | null;
  conductor: string | null;        // Stage 4+
  pieces: string[];                // Stage 3+
  korpsnr: number | null;          // For matching with historical data
  image_url: string | null;        // Reserved for future use
}
```

## Visual Design

- **Stage Badges**: Color-coded by stage (blue→green→yellow→purple)
- **Division Cards**: Elevated cards with shadow for visual separation
- **Entry Rows**: 
  - Numbered play order in circular badges
  - Left border accent for entries with scheduled times
  - Hover effects for interactivity
- **Responsive**: Adapts to mobile/tablet layouts

## Future Enhancements

Possible improvements for future iterations:

1. **Historical Context**: Link orchestras to their historical performance trajectories
2. **Live Updates**: WebSocket or polling for real-time schedule changes
3. **Notifications**: Alert users when data stage progresses
4. **Piece Details**: Link to piece metadata when announced (Stage 3)
5. **Conductor Profiles**: Link to conductor historical data (Stage 4)
6. **Venue Maps**: Interactive venue maps and seating
7. **Competition Day**: Live results integration during competition
8. **Multi-year**: Support for 2027, 2028, etc.

## Notes

- Data is read-only in this view (no user interactions that modify data)
- Automatically switches between wind/brass data based on app's band type selection
- Data files are cached by browser (consider cache-busting for updates)
- After competition completes, this data can be archived and migrated to standard results format
